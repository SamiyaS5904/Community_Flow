FORMATTING (a document, not a chat message):
- This is a multi-page guide. Length is set by the structure you are asked for,
  not by a message limit — write each field as fully as it deserves.
- Plain prose. No markdown, no bullet characters, no emoji inside text fields;
  the page layout supplies all formatting.
- Short paragraphs, 2-3 sentences each. Separate them with a blank line.
- Every section carries a worked example. A section without one is incomplete.
